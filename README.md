# Turkish Coffee Game
This project turns the Turkish coffee-making process into a mini game.
In each round, the player is given a random Turkish coffee recipe: unsweetened, medium sugar, or sweet.
If the player makes the recipe incorrectly, they lose points. If they complete the recipe correctly, they gain points.

The coffee-making steps are:
1. Read the current recipe and ingredient list from the recipe board.
2. Add water.
3. Take the spoon and add the required amount of sugar.
4. Take the spoon and add the required amount of coffee.
5. Wait for the fire to burn and the coffee to brew in the cezve.
6. Pick up the cezve and pour the coffee into the cup.
